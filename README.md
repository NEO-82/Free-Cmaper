# Free Camper · 잠시, 숲으로

작은 사계절 캠핑 월드를 탐험하는 한국어 브라우저 게임의 첫 프로토타입입니다.

## 실행

Node.js 22.12 이상이 필요합니다. 현재 환경에서는 Node.js 24로 검증했습니다.

```sh
cd /workspace/Free-Cmaper
npm ci --cache /workspace/.npm-cache
npm run dev
```

배포용 빌드: `npm run build`. 개발 서버 기본 포트는 5173입니다.

## 플레이

첫 화면은 언덕 위에 앉아 석양을 바라보는 주인공과 게임 시작·옵션 메뉴입니다. 게임 시작을 누른 뒤 집 준비 화면에서 연령·성별·체형과 계절을 고르고, 기본 장비 6종을 체크하세요. 차 또는 도보로 출발합니다. 출발은 05:00이며 차량은 1시간, 도보는 3시간 뒤 도착합니다. 현실 120초가 게임 1시간이고, 출발부터 168시간이 지나면 여행이 끝납니다. 계절은 한 여행 동안 고정됩니다.

- WASD / 방향키: 이동. 차를 선택하면 이동 속도가 빠릅니다.
- 마우스: 좌우·상하 시점 이동. 게임 화면을 클릭하면 포인터가 고정되며, Esc로 해제합니다. 고정이 지원되지 않으면 화면 위에서 마우스를 움직여 시점을 이동합니다. 터치 화면은 드래그로 시점을 조정합니다. 휠: 확대/축소.
- Space: 서 있는 상태에서 점프. 착지 전에는 다시 점프할 수 없습니다.
- 왼쪽 Shift + 이동: 천천히 이동. 오른쪽 Shift는 적용되지 않습니다.
- C: 앉기 / 일어서기. V: 엎드리기 / 일어서기. 각 자세에 맞게 이동 속도도 줄어듭니다.
- B: 백팩 열기 / 닫기. 보유 기본 장비와 구매한 장비를 펼쳐 봅니다. 백팩을 보는 동안 시간, 이동, 날씨 효과, 동물 이동과 사건 판정이 정지합니다. 닫기 버튼 또는 Esc로도 닫을 수 있습니다. 기존에 일시 정지했다면 백팩을 닫아도 정지를 유지합니다.
- 지도 클릭: 목적지까지 자동 이동. 지도 위쪽은 북쪽입니다.
- 캠핑하기: 현재 위치 옆에 텐트를 설치하거나 이전합니다.
- 주변 정리 / 퇴치 장비 설치: 야간 동물 접근 확률을 줄입니다.
- 상점: 북쪽 오두막 근처에서 새 물건·중고품 구매, 보유 물건 판매.
- 1시간 휴식: 시간을 한 시간 진행합니다. 잠시 쉬기는 시간을 정지합니다.

## 옵션

첫 메뉴 또는 게임 우측 상단의 옵션에서 밝기(60–150%), 마우스 감도(0.2–3배), 좌우·상하 마우스 반전, 한국어·영어를 변경할 수 있습니다. 설정은 즉시 적용되고 브라우저의 로컬 저장소에 보관됩니다. 저장소를 사용할 수 없는 브라우저에서는 현재 플레이에만 적용됩니다. 게임 내 옵션 화면을 열어도 시간이 멈춥니다. 밝기는 3D 장면의 노출을 조정하며 메뉴 가독성은 유지합니다.

월드 동쪽 약 1/3은 바다, 북쪽은 산, 남쪽은 강과 호수입니다. 꽃바람·소나기·낙엽·눈·안개와 낮밤 조명을 사용합니다. 위험 동물 판정은 게임 시간당 한 번이며 낮 5%, 밤 기본 25%, 청소와 퇴치 장비 설치를 모두 하면 0.5%입니다.

## 구현 범위와 제한

초기 플레이 흐름과 미션, 거래, 시간, 날씨, 텐트 이전이 구현되어 있습니다. 현재 집은 준비 UI이며 별도의 실내 3D 공간은 없습니다. 차 선택은 이동 속도로 표현하며 운전 물리나 차량 모델은 없습니다. 인물은 단순 도형이며 성별은 옷 색상, 체형은 몸통 폭에 반영되고 연령별 모델은 아직 없습니다. 동물은 낮/밤에 다른 도형 무리로 나타나고 위험 동물 접근은 알림과 퇴치 상태로 표현합니다. 추격·공격, 식사·체온 시뮬레이션, 날씨 장비의 실제 성능 차이, 저장/불러오기와 사운드는 후속 작업입니다. 날씨 장비는 구매와 권장 알림까지 구현되어 있습니다.

## 검증

- `npm test`: 감도·반전·시점 제한, 옵션 입력 검증, 느린 이동과 자세 전환, 점프 물리·착지, 백팩/옵션/수동 정지의 독립성, 주요 번역에 대한 7개 테스트.
- `npm run build`: 배포 빌드.
- 시스템 Chromium에서 Playwright로 첫 메뉴, 옵션 저장 후 새로고침, 한국어/영어 전환, 장비 준비 조건, 도보 도착 시각, WASD 이동, C/V 자세 전환, 점프·착지, 백팩 6종 표시, 백팩 중 시간·이동 정지와 닫기 후 재개, 기존 수동 정지 유지, 캠핑·정리·휴식, 모바일 백팩 표시, 귀가를 확인했습니다. 런타임 오류는 없었습니다.
- 전체 일주일 실시간 플레이와 모든 무작위 사건 조합은 검증하지 않았습니다.

## 웹 배포

GitHub Pages용 워크플로는 `.github/workflows/pages.yml`에 있습니다. 저장소의 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택한 뒤, `main`에 푸시하거나 Actions에서 `Deploy game to GitHub Pages`를 실행하세요. 테스트와 빌드가 통과하면 배포합니다. 실제 접속 주소는 성공한 배포 작업의 `github-pages` 환경에서 확인하세요.

`dist/`는 정적 호스팅에 그대로 업로드할 수 있습니다. 상대 경로 에셋을 사용하므로 루트 또는 저장소 하위 경로에서 실행할 수 있습니다. 브라우저의 마우스 고정 기능을 위해 HTTPS 호스팅을 사용하세요.
