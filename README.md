# Free Camper · 잠시, 숲으로

사계절 캠핑 월드를 자유롭게 탐험하는 한국어·영어 브라우저 게임입니다. 소스와 테스트 다운로드 파일은 공개하며, 게임 웹 배포는 하지 않습니다.

## 설치 없이 로컬에서 테스트

[테스트 ZIP 다운로드](https://github.com/NEO-82/Free-Cmaper/raw/refs/heads/main/downloads/Free-Camper-Test.zip) → 압축 풀기 → `Free-Camper.html`을 Chrome 또는 Edge로 열기 → **게임 시작**.

단일 HTML에는 게임 코드와 스타일이 포함됩니다. 별도 설치·서버·인터넷 연결은 필요 없지만 JavaScript와 WebGL 2를 지원하는 브라우저가 필요합니다. 브라우저 관리 정책은 로컬 파일 실행을 제한할 수 있습니다. 소스의 `index.html`을 직접 여는 방식과는 다릅니다.

## 개발 실행

Node.js 22.12 이상이 필요하며 현재 환경에서는 Node.js 24를 사용합니다.

```sh
npm ci
npm start
```

`npm start`는 본인 컴퓨터의 로컬 서버를 실행하고 브라우저를 엽니다. 플레이하는 동안 터미널을 열어 두세요. 클라우드 내부 개발 서버에는 `npm run dev`를 사용합니다. 기본 포트는 5173입니다.

- `npm test`: 자동 테스트.
- `npm run build`: 정적 웹 빌드.
- `npm run build:offline`: 설치 없이 열 수 있는 `dist-offline/Free-Camper.html` 생성.

게임 파일 또는 3D 그래픽 초기화가 실패하면 오류 안내를 표시합니다. 그래픽 오류라면 Chrome/Edge의 그래픽 가속을 켜고 브라우저를 재시작하세요. GitHub Actions는 플레이 화면이 아니며, 공개 배포 워크플로는 제거한 상태입니다.

## 월드와 캠핑

월드 크기는 **1,000 × 800m**로 직전 700 × 570m의 약 **2.005배 면적**입니다. 동쪽 약 1/3은 바다, 북쪽은 산, 남쪽은 넓어진 강과 호수입니다. 나무 **1,050그루**와 바위 **68개**가 있으며, 기존 상점과 정상 위치는 유지해 익숙한 이동·상호작용을 이어갈 수 있습니다.

산길을 따라 또는 산길 밖으로 자유롭게 오르내릴 수 있습니다. 북쪽 정상은 고도 **88m**, 지름 **40m**의 평평한 캠핑 공간입니다. 캠핑은 텐트 전체가 들어갈 평평하고 장애물 없는 땅에서만 가능합니다. 주변이 빽빽하거나 경사가 심하면 다른 장소를 찾으세요. 텐트 재설치는 기존 텐트를 옮기며, 새로 구매한 디자인을 적용합니다.

게임은 집 준비 화면에서 인물·체형·계절과 기본 장비 6종을 고르는 것으로 시작합니다. 05:00 출발, 차량은 1시간 뒤, 도보는 3시간 뒤 도착합니다. 현실 120초가 게임 1시간이며 최대 168시간 동안 캠핑합니다. 계절은 여행 동안 고정되고 날씨와 낮밤은 변합니다.

## 그래픽 방향

첨부한 예시의 밝고 선명한 모험 게임 분위기에 맞춰 녹색 수관과 풀·고사리·꽃 군락, 따뜻한 황갈색의 층진 바위, 둥글고 입체적인 형태를 사용합니다. 가까운 시점과 부드러운 햇빛, 그라데이션 하늘·구름, 모양이 있는 눈·비·꽃잎으로 장면의 깊이와 날씨 표현을 보완했습니다. 그래픽은 외부 상용 에셋을 복제하지 않고 절차적 모델과 재질로 구성합니다.

캐릭터는 얼굴·머리카락·관절·옷·배낭의 세부 형태를 갖추고 연령·성별·체형 선택을 모델에 반영합니다. 상점은 층진 목재 외벽·지붕 타일·돌 기초·꽃 상자와 상세한 주인·진열품을, 텐트는 봉제선·지퍼·통풍구·고정끈·침낭과 소품을 표현합니다. 기존 문·가구 충돌과 거래·출입 시점은 유지합니다.

## 조작과 상호작용

| 조작 | 동작 |
|---|---|
| WASD / 방향키 | 이동. 나무·바위·벽·닫힌 문과 충돌합니다. |
| 마우스 | 좌우·상하 시점. 화면 클릭으로 포인터 고정, Esc로 해제. 고정 불가 시 마우스 드래그, 터치도 드래그. |
| Space | 서 있을 때 점프. |
| 왼쪽 Shift + 이동 | 천천히 이동. |
| C / V | 앉기 / 엎드리기. 같은 키를 다시 누르면 일어납니다. |
| F | 가까운 대상에 화면에 표시된 행동 수행. |
| B | 백팩 열기·닫기. 확인 중 시간과 월드 정지. |
| 지도 클릭 | 야외에서 목적지 방향으로 이동. 장애물을 자동 우회하지는 않습니다. |

백팩·옵션·거래 화면 중에는 시간과 월드가 정지합니다. 기존 수동 일시 정지 상태는 화면을 닫아도 유지됩니다.

- 모든 나무: 도끼로 세 번 베면 나무가 쓰러지고 장작 3개를 얻습니다.
- 바위: 곡괭이로 세 번 캐면 돌 3개를 얻습니다. 삽으로 땅을 파면 흙을 얻습니다.
- 허브·물가: 채집하거나 물을 담습니다. 표지판과 동물은 살펴볼 수 있습니다.
- 상점·텐트 문: F로 열고 닫습니다. 출입구에서 한 걸음 물러나야 문을 닫을 수 있습니다.
- 캠프: 장작으로 모닥불을 켜고 끄며, 음식물 정리와 퇴치 장비 설치로 야간 위험을 줄입니다.

상호작용 대상은 나무·바위·채집물·물·표지판·문·상점 가구·주인·텐트 장비·모닥불처럼 게임 행동이 있는 오브젝트입니다. 풀 장식·하늘·바다 거품 등 배경 장식은 풍경입니다.

## 상점과 텐트

북쪽 오두막의 문을 **F**로 연 뒤 실제로 걸어 들어가세요. 내부에서는 숄더뷰로 바뀝니다. 안쪽 계산대의 주인 가까이에서 F를 누르면 거래합니다. 진열대에서는 상품 안내를 확인할 수 있습니다.

도끼·삽·곡괭이·밧줄과 계절용 장비를 구매할 수 있고, 중고품은 정가의 65%, 되팔기는 정가의 40%입니다. 벌목한 장작은 개당 1,200원에 판매합니다.

텐트는 크기 3종, 형태 3종(돔·리지·터널), 색상 4종, 원단 2종(직조 무늬 캔버스·격자 무늬 립스톱)을 선택합니다. 기본 크기는 **18 × 16 × 7m**로 이전 텐트 폭 6m의 3배입니다. 큰 크기와 형태·원단에 따라 가격이 달라집니다.

출입구를 열고 걸어 들어가면 **1인칭**으로 전환됩니다. 내부 침낭에서 한 시간 쉬기, 랜턴 켜고 끄기, 백팩 확인도 F로 사용합니다. 구매한 텐트 설정은 다음 설치에 반영됩니다.

## 옵션과 현재 제한

밝기·마우스 감도·좌우/상하 반전·한국어/영어를 지원하고 설정은 브라우저에 저장합니다. 게임 진행 저장/불러오기는 아직 없습니다.

집은 준비 UI이며 별도 실내 공간은 없습니다. 차량 선택은 이동 속도 차이로 표현하며 운전 물리는 없습니다. 야생동물은 낮밤 출현·관찰·위험 알림과 퇴치 기능을 사용하며 정교한 추격/공격은 없습니다. 식사·체온 시뮬레이션, 계절용 장비의 실제 성능 차이, 사운드도 후속 구현 범위입니다.

## 검증

자동 검사 **44개**와 웹·오프라인 빌드가 통과했습니다. Chromium에서 상점 문 충돌과 숄더뷰·주인 거래, 도구와 텐트 구성 구매, 나무 충돌·벌목, 채광·삽질, 정상 캠핑, 텐트 출입·1인칭·문 닫기, 백팩 시간 정지를 확인했습니다. 네트워크를 차단한 단일 HTML에서도 시작·이동·F 문 열기·상점 진입·백팩 동작을 확인했고 HTTP 요청과 런타임 오류는 없었습니다. 최신 테스트 ZIP도 갱신했습니다.

[실제 플레이 화면](docs/screenshots/play-preview.png)을 참고하세요. 클라우드 관리형 브라우저의 file:// 차단과 사용자 컴퓨터의 직접 파일 실행은 구분합니다. 전체 일주일 실시간 플레이와 모든 무작위 사건 조합은 검증 대상에 포함하지 않습니다.
