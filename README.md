# Free Camper · 잠시, 숲으로

사계절 캠핑 월드를 자유롭게 탐험하는 한국어·영어 브라우저 게임입니다. 소스와 테스트 다운로드 파일은 공개하며, 게임 웹 배포는 하지 않습니다.

## 설치 없이 로컬에서 테스트

[테스트 ZIP 다운로드](https://github.com/NEO-82/Free-Cmaper/raw/refs/heads/main/downloads/Free-Camper-Test.zip) → 압축 풀기 → `Free-Camper.html`을 Chrome 또는 Edge로 열기 → **게임 시작**.

단일 HTML에는 게임 코드와 스타일이 포함됩니다. 별도 설치·서버·인터넷 연결은 필요 없지만 JavaScript와 WebGL 2를 지원하는 브라우저가 필요합니다. 브라우저 관리 정책은 로컬 파일 실행을 제한할 수 있습니다. 소스의 `index.html`을 직접 여는 방식과는 다릅니다.

## 개발 실행

Node.js 22.12 이상이 필요하며 현재 환경에서는 Node.js 24를 사용합니다.

```sh
npm ci
npm start
```

`npm start`는 본인 컴퓨터의 로컬 서버를 실행하고 브라우저를 엽니다. 플레이하는 동안 터미널을 열어 두세요. 클라우드 내부 개발 서버에는 `npm run dev`를 사용합니다. 기본 포트는 5173입니다.

- `npm test`: 자동 테스트.
- `npm run build`: 정적 웹 빌드.
- `npm run build:offline`: 설치 없이 열 수 있는 `dist-offline/Free-Camper.html` 생성.

게임 파일 또는 3D 그래픽 초기화가 실패하면 오류 안내를 표시합니다. 그래픽 오류라면 Chrome/Edge의 그래픽 가속을 켜고 브라우저를 재시작하세요. GitHub Actions는 플레이 화면이 아니며, 공개 배포 워크플로는 제거한 상태입니다.

## 월드와 캠핑

이동 가능한 월드는 **약 3,014 × 2,390m**(7.2036km²)로 직전 1,740 × 1,380m의 정확히 **3배 면적**입니다. 사방에 보이지 않는 이동 경계가 있으며 바다에서도 경계를 넘을 수 없습니다. 경계 밖에는 이동 영역 면적의 **2배인 배경 지형**이 둘러싸고, 먼 끝에는 절차적으로 그린 **2D 산 파노라마**가 이어집니다. 동쪽 약 1/3은 바다, 북쪽은 산, 남쪽은 강과 호수입니다. 나무 **3,600그루**와 바위 **220개**가 있습니다. 상점과 정상 위치는 유지합니다.

날씨는 게임 한 시간마다 **맑음 70% · 비/눈 10% · 흐림 10% · 안개 10%**로 독립 추첨합니다. 겨울의 강수는 눈이며, 나머지 계절에는 비가 옵니다. 맑은 날은 구름이 전혀 없을 수도 있고, 흐림·비·눈·안개에서는 구름의 양·높이·색·바람이 달라집니다.

모래사장을 걸어 바다에 들어가 수영하고, **Q로 잠수 / Space로 상승**할 수 있습니다. 물속에서는 1인칭으로 해양 생물을 살펴봅니다. 물고기144마리·바다거북10마리와 산호·해초 군락·기포를 관찰하고, 꽃게14마리·소라20개·바닷가제16마리는 **F**로 채집합니다. 호수와 강에도 들어갈 수 있습니다. 해안선에는 최대 약16cm의 작은 파도가 천천히 밀려오고, 옅은 물거품이 약1~3m 범위에서 오르내립니다. 파도는 실제 모래사장 높이를 따라 배치한 시각 효과이며 수영·채집의 물리 기준 높이는 유지합니다. ESC·지도·가방으로 게임을 멈추면 파도도 멈춥니다.

기준 정상은 **88→176m**로 높였고, 불규칙한 북쪽 산맥·노출 암벽·돌출된 바위 구간을 추가했습니다. 경사가 완만한 곳은 산길 밖으로도 자유롭게 이동하지만, 급경사 암벽은 걸어 올라가거나 뛰어서 통과할 수 없습니다. **폭10m·길이 약1.09km의 길**이 산을 크게 돌아 정상까지 이어집니다. 가장 가파른 길 구간도 약14도(경사율24.5% 이하)로 낮췄고, 실제 캐릭터 물리와 월드 장애물을 포함해 입구부터 정상까지 통과했습니다. M 전체 지도에서도 새 길을 볼 수 있습니다. 북쪽 정상은 고도 **176m**, 지름 **40m**의 평평한 캠핑 공간입니다. 텐트 전체가 들어갈 장애물 없는 육지에 설치하면 **입구 높이를 기준으로 텐트 면적만 평평하게** 만듭니다. 경사면의 낮은 쪽은 흙으로 메우고 높은 쪽은 깎아 바닥이 뜨지 않도록 합니다. 텐트 밖의 지형은 유지하며 물가·나무·바위·건물이 겹치는 장소에는 설치할 수 없습니다. 텐트 재설치는 기존 텐트를 옮기며, 이전 장소의 지형을 복원하고 새로 구매한 디자인을 적용합니다.

게임 시작 후 동물 캐릭터·계절을 고르고 **실제 3D 집 내부**에서 준비합니다. WASD로 가구 사이를 걸어 텐트·수면용품·복장·조리도구·음식·생존장비 가까이에서 **F**를 눌러 배낭에 담으세요. 여섯 가지를 챙긴 뒤 오른쪽 현관에서 F를 누르면 **버스·기차·승용차·SUV·스쿠터·캠핑카**를 선택합니다. 준비 시간은 05:00에 머물며, 버스는 2시간, 기차·스쿠터는 1시간 30분, 승용차·SUV는 1시간 뒤 도착합니다. 도착 지점은 서쪽 맵 경계 가까이의 작은 정류장·기차역·주차장입니다. 현실 120초가 게임 1시간이며 최대 168시간 동안 캠핑합니다. 계절은 여행 동안 고정되고 날씨와 낮밤은 변합니다.

## 그래픽 방향

플레이어 주변에는 재사용하는 풀 타일을 배치해 넓어진 맵 전체에서 풀이 촘촘하게 보입니다. 길·상점 내부·설치한 텐트 아래는 비웁니다. 길 표면을 주변 바닥보다 최대4cm 낮췄고, 길 아래 바탕 메시를16cm 내려 겹침을 없앴습니다. 발·타이어·길은 같은 높이를 사용하므로 길이 발을 덮는 문제가 없습니다. 길은 폭과 길이 방향으로 촘촘히 나눠 지형과 맞춥니다. 멀리 있는 산 배경의 떠 있는 `^` 장식은 제거했습니다.

해상도는 유지하면서 둥근 나무와 부드러운 녹색·크림색, 큰 눈과 둥근 형태의 캐릭터·동물, 종이 같은 메뉴로 귀엽고 편안한 분위기를 표현합니다. 참고 작품의 상용 에셋을 사용하지 않으며 모델·재질·산 배경·음악과 효과음은 자체 절차 생성 방식입니다. 부드러운 햇빛과 그라데이션 하늘, 날씨별 구름·비·눈을 사용합니다.

플레이어는 사람이 아닌 동물 캠퍼입니다. 기본은 **골든리트리버 강아지**이며 **고양이·양·너구리·사슴** 중 고릅니다. 골든리트리버의 황금색 털·처진 귀·둥근 얼굴, 고양이의 뾰족한 귀·수염, 양의 양털, 너구리의 눈 무늬·줄무늬 꼬리, 사슴의 귀·작은 뿔·반점을 각각 표현했습니다. 발과 앞발, 종별 꼬리, 작은 배낭을 사용하고 사람의 나이·성별·체형 선택은 제거했습니다. 얼굴 전체는 하나의 둥근 3D 머리 형태로 만들고 **눈·코·입·수염·얼굴 무늬는 2D 텍스처**로 표현합니다. 눈은 주기적으로 깜빡이고, 입은 가만히 있을 때와 달리기·수영 중 서로 다르게 움직입니다. 귀·뿔·양털·꼬리는 종별 3D 형태를 유지합니다. 기존 이동·달리기·앉기·엎드리기·수영·침대 동작과 차량 운전을 유지합니다.

## 조작과 상호작용

| 조작 | 동작 |
|---|---|
| WASD / 방향키 | 이동. 나무·바위·벽·닫힌 문과 충돌합니다. |
| 마우스 휠 | 도보·차량 시점 거리 조절. 최대한 당기면 1인칭, 다시 밀면 3인칭으로 복귀. |
| 마우스 | 좌우·상하 시점과 하늘 꼭대기 보기. 화면 클릭으로 포인터 고정, ESC로 메뉴 열기. 고정 불가 시 마우스 드래그, 터치도 드래그. |
| Space | 차량에서 제동, 지상에서 중력 점프, 물속에서 상승. 텐트 안과 침대에서 쉬는 동안에는 점프 불가. |
| Q | 물속에서 잠수. |
| 왼쪽 Shift + 이동 | 달리기: 걷기의 **3배** 속도. |
| 왼쪽 Ctrl + 이동 | 누르는 동안 살짝 숙여 천천히 걷기. 놓으면 원래 자세로 복귀. |
| C / V | 앉기 / 엎드리기. 같은 키를 다시 누르면 일어납니다. |
| F | 집 장비 챙기기·현관 이동수단 선택·차량 승하차·가까운 대상과 상호작용. 침대 옆에서는 누워 하늘 보기, 누운 중에는 일어나기. |
| B | 머리 위 말풍선 백팩 열기·닫기. 확인 중 월드 정지, 방향키로 물품 살펴보기. |
| M | 시간을 멈추고 전체 월드맵 열기·닫기. 현재 위치·차량·정류장·기차역·상점·정상·캠프 표시. |
| ESC | 정지 메뉴 열기·닫기. 캠핑·정리·퇴치·휴식·옵션을 마우스로 선택. |

전체 이동 속도를 직전의 **2배**로 올렸습니다. 교통편과 관계없이 야외 기본 **8m/s**, 집·상점 실내 **3m/s**, 수영 **3.4m/s**이며 Shift 달리기는 각각 **24/9m/s**입니다. Ctrl은 기본 걷기의40% 속도이며 Shift와 함께 누르면 천천히 걷기를 우선합니다. C/V의 고정 자세와 별도로 Ctrl은 누르는 동안만 적용됩니다.

차량은 **승용차·SUV·스쿠터·캠핑카** 4종이며 선택한 차량이 입구 주차장에 도착합니다. 가까이 가서 **F**로 타고, **W/S 전진·후진, A/D 방향 전환, Space 제동, 마우스 시점**으로 조작합니다. 안전하게 멈춘 뒤 F로 내리세요. 도로 밖도 자유롭게 운전하지만 나무·바위·건물·급경사·물·월드 경계는 통과하지 못합니다. 최고 속도를 직전 버전의 **2/3**로 낮췄습니다. 승용차 약42.67m/s, SUV 약37.33m/s, 스쿠터 약26.67m/s, 캠핑카32m/s입니다. 가속·제동 성능은 유지합니다. 앞뒤·좌우 바퀴 접지점을 각각 읽어 차량 방향에 맞는 피치·롤을 계산하고, 스프링/댐퍼 서스펜션·가속/제동 하중 이동·커브 기울기·언덕 마루에서의 중력 낙하를 적용합니다. 바퀴도 각 지면 높이에 맞춰 움직이며, 정차 후 출렁임은 서서히 안정됩니다. 버스·기차 도착은 도보로 시작하며 정류장·역에서 F로 안내를 볼 수 있습니다.

M 지도는 전체 이동 영역과 주요 장소를 보여주며 **지도에서 시간을 멈춥니다**. 운전 중에도 위치·속도가 정지합니다. M/ESC/닫기 버튼으로 복귀하며 ESC 메뉴에서 열었다면 다시 정지 메뉴로 돌아갑니다. 지도 클릭 이동 기능은 없습니다.

플레이 중 마우스는 시점 조작에 사용하며 HUD와 미니맵은 읽기 전용입니다. **선택 가능한 UI는 ESC 정지 상태에서만 마우스로 조작**합니다. B로 여는 말풍선 백팩은 읽기·방향키 선택만 가능하고, ESC 메뉴에서 연 백팩은 마우스 선택도 가능합니다. 주인에게 F로 말을 걸면 정지 상태로 거래하며, 거래·옵션을 닫으면 ESC 메뉴로 돌아갑니다.

- 해변 꽃게14마리·소라20개, 얕은 연안의 바닷가제16마리: 가까이에서 **F**로 채집해 종류별 식재료로 가방에 보관합니다. 한 개체는 한 번만 채집되며 월드 갱신 후 다시 나타나지 않습니다. 추후 요리·섭취용 데이터로 구분하며 현재 해산물 섭취 기능은 없습니다. 물고기·바다거북·산호는 관찰 대상으로 유지합니다.
- 모든 나무: 도끼로 세 번 베면 나무가 쓰러지고 장작 3개를 얻습니다.
- 바위: 곡괭이로 세 번 캐면 돌 3개를 얻습니다. 삽으로 땅을 파면 흙을 얻습니다.
- 허브·물가: 채집하거나 물을 담습니다. 표지판과 동물은 살펴볼 수 있습니다.
- 상점·텐트 문: F로 열고 닫습니다. 출입구에서 한 걸음 물러나야 문을 닫을 수 있습니다.
- 캠프: ESC 메뉴에서 텐트를 설치하고, 음식물 정리와 퇴치 장비 설치로 야간 위험을 줄입니다. 텐트 설치 시 모닥불은 생성하지 않습니다.

상호작용 대상은 나무·바위·채집물·물·표지판·문·상점 가구·주인·텐트 장비·해양 생물처럼 게임 행동이 있는 오브젝트입니다. 풀 장식·하늘·바다 거품 등 배경 장식은 풍경입니다.

## 캠핑카

현관의 이동수단에서 **캠핑카**를 선택합니다. 실제 알코브형 모터홈을 모티브로 운전석 위 침상, 측면 출입문, 창문, 천창과 지붕 패널을 표현했습니다. 외형은 **길이8 × 폭3.8 × 높이4.1m**로 기본 텐트(9 × 8 × 5m)보다 작고 실제 차량처럼 폭이 좁습니다.

정차한 캠핑카의 **앞쪽**에서 **F**를 누르면 바로 운전석에 탑승하고, **뒤쪽 생활공간 출입구**에서 **F**를 누르면 실내에 들어갑니다. 캠핑카가 어느 방향을 향하든 앞·뒤 구분은 차량 방향을 기준으로 합니다. **WASD**로 1인칭 이동하고 가구 가까이에서 **F**를 누릅니다. 뒤쪽 침대에서는 눕기·일어나기, 조리대에서는 음식1개를 사용해 식사 준비, 화장실에서는 사용·정리를 할 수 있습니다. 앞쪽 운전석에서 F로 운전을 시작하고 정차 후 F로 하차합니다. 실내 뒤쪽 측면 출입문에서도 F로 밖으로 나갈 수 있습니다. 측면 창문과 앞쪽 유리는 투명하며, 실제 주차 위치의 숲·바다·하늘을 볼 수 있습니다. 실내는 차량의 주차 방향과 경사를 따릅니다. 안전한 하차 공간이 없으면 출입을 막습니다.

실내에서 **ESC → 캠핑카 내부 꾸미기**를 열어 목재(오크·월넛·화이트), 침구(세이지·블루·테라코타), 조리대 배치(좌·우)를 즉시 변경합니다. 양쪽 배치 모두 중앙 통로와 가구 접근 공간을 확보했습니다. 꾸미기 설정은 브라우저에 저장하며 게임 진행 저장과는 별개입니다.

## 상점과 텐트

북쪽 오두막의 문을 **F**로 연 뒤 실제로 걸어 들어가세요. 내부에서는 숄더뷰로 바뀌며, 지붕과 실제 목재 천장을 유지하고 따뜻한 실내등 두 개로 내부를 밝힙니다. 가방을 열어도 천장을 숨기지 않습니다. 안쪽 계산대의 주인 가까이에서 F를 누르면 거래합니다. 진열대에서는 상품 안내를 확인할 수 있습니다.

도끼·삽·곡괭이·밧줄과 계절용 장비를 구매할 수 있고, 중고품은 정가의 65%, 되팔기는 정가의 40%입니다. 벌목한 장작은 개당 1,200원에 판매합니다.

텐트는 크기 3종, 형태 3종(돔·리지·터널), 색상 4종, 원단 2종(직조 무늬 캔버스·격자 무늬 립스톱)을 선택합니다. 기본 크기는 **9 × 8 × 5m**입니다. 바닥 넓이 9×8m는 유지하고 높이만 3.5→5m로 올렸습니다. 사람 크기의 출입구와 내부 침낭·랜턴은 유지합니다. 큰 크기와 형태·원단에 따라 가격이 달라집니다.

출입구를 열고 걸어 들어가면 **1인칭**으로 전환됩니다. 침대 옆에서 **F**를 누르면 앉았다가 등을 대고 눕는 모션 뒤 1인칭으로 **투명 천창 너머 하늘**을 바라봅니다. 양쪽 침대에서 사용하며, **F**를 다시 누르면 일어나 원래 서 있던 자리로 돌아갑니다. 누워 있는 동안에는 이동과 점프를 막고, 시간·날씨는 계속 흐릅니다. ESC 메뉴와 B 가방에서는 모션과 월드가 함께 멈춥니다. 텐트 내부에서는 서 있을 때도 점프할 수 없습니다. 랜턴과 백팩도 F로 사용합니다. 구매한 텐트 설정은 다음 설치에 반영됩니다.

## 사람 이동 물리와 수영

캐릭터는 최대1/120초 간격으로 중력·수평 속도·공중 조작·발판·천장·장애물 높이를 계산합니다. 걷기/달리기 속도는 유지하고 짧게 가속·감속하며, 점프 시 도약 속도를 유지합니다. 기본 점프 최고 높이를 기존의2배인 약4.3m로 높여 낮은 바위·가구를 넘거나 그 위에 착지하고, **Shift를 누르고 실제로 이동하다 점프하면 같은 속도의 일반 점프보다 최고 높이와 비행 거리가 약1.2배 증가**합니다. Shift만 누르고 제자리 점프하거나 공중에서 Shift를 누를 때는 추가 도약이 생기지 않습니다. 달리기와 점프를 함께 사용하면 좁은 강을 넘을 수 있습니다. 나무·높은 벽·급경사와 맵 경계는 계속 막힙니다. 나무마다 첫 높이2.6m부터 약2.7m 간격의 가지 발판이 있어 차례로 점프해 나무 꼭대기까지 올라갈 수 있습니다. 가지는 아래에서 위로 점프할 때 통과하고 내려올 때 착지하며, 줄기는 옆으로 통과하지 못합니다. 바위는 렌더링한 바위·이끼 표면에 광선을 쏴 실제 높이에 맞춰 발을 디딥니다. 발판 밖으로 나가거나 벌목·채광으로 발판이 사라지면 중력을 받아 떨어집니다.

공중에서 물 위를 지나도 점프를 취소하지 않습니다. 실제로 물에 빠지면 부력과 물의 저항이 작동합니다. 이동 중에는 몸을 수평으로 기울이고 양팔 젓기·발차기·물결·물방울을 표현하며, 멈추면 선 채로 뜨는 물장구 동작으로 전환합니다. Q 잠수/Space 상승은 유지하고, 강·호수의 얕은 가장자리에서는 자연스럽게 걸어 나옵니다. ESC/M/B 정지 중에는 모션과 물리도 함께 멈춥니다.

일반 야생동물(사슴·토끼·여우·올빼미)은 여행마다 육지의 무작위 위치에 배치합니다. 위험 동물은 **곰·뱀·늑대**이며 **23:00 이상부터 다음 날 06:00 미만**에만 등장합니다. 기존 판정 간격인 게임 시간 한 시간(현실120초)마다 기본 **5% 확률**로 추첨하며, 한 번에 한 마리만 나타납니다. 기존처럼 청소와 퇴치 장비를 모두 갖추면 확률이0.5%로 낮아집니다. 실내·물속에서는 등장하지 않고, 실내로 피하거나 퇴치하면 사라집니다. 오전6시가 되면 남아 있던 위험 동물도 사라집니다.

## 낮과 밤의 하늘

먼 비행기는 평균 게임 시간 **1시간에 한 대**(매번 54~66분 간격) 나타나 **무작위 방향으로 맵 끝에서 반대편 끝까지** 날아갑니다. 두 줄의 꼬리구름은 뒤쪽으로 퍼지고 비행기가 사라진 뒤 천천히 흐려집니다. 비행 고도는 약1,150~1,370m입니다.

밤에는 별1,400개가 각각 반짝이며, **은하수는 2~3일 간격의 밤**에 보입니다. **겨울의 맑은 밤**에는 북쪽 하늘에 천천히 움직이는 오로라가 나타납니다. 달과 태양은 시간에 따라 서로 반대쪽 하늘을 지나며 구름·강수·안개에 가려지거나 약해집니다. 은하수·별·오로라는 밝은 낮이나 궂은 날씨에는 숨겨집니다. 모든 하늘 연출은 ESC·M·B의 게임 정지와 함께 멈춥니다. 일주일 동안의 무작위 일정은 여행마다 새로 정하며 진행 저장 기능은 아직 없습니다.

## 소리

게임 시작 버튼 등 사용자 조작 후 잔잔한 멜로디와 화음이 재생됩니다. 야간 위험 동물이 나타나면 긴박한 음악으로 전환되고, 퇴치하거나 실내로 피하면 원래 음악으로 돌아갑니다. 메뉴 마우스 진입·선택, 귀여운 아이템 선택음과 문·벌목·채광·삽질·채집·발걸음·물소리·점프·퇴치 효과음을 제공합니다. 오프라인 HTML에도 모두 포함됩니다.

## 옵션과 현재 제한

밝기·마우스 감도·좌우/상하 반전·한국어/영어·BGM 음량·효과음 음량·전체 음소거를 지원하고 설정은 브라우저에 저장합니다. 게임 진행 저장/불러오기는 아직 없습니다.

차량은 첫 구현의 간단한 운전 모델이며 연료·충돌 피해·차량 구매·대중교통의 실시간 운행은 아직 없습니다. 야생동물은 낮밤 출현·관찰·위험 알림과 퇴치 기능을 사용하며 정교한 추격/공격은 없습니다. 식사·체온 시뮬레이션과 계절용 장비의 실제 성능 차이는 후속 구현 범위입니다. 해양 생물은 서식·유영·관찰을 제공하는 첫 구현이며 꽃게·소라·바닷가제 채집을 지원하며, 해산물 요리·섭취와 먹이사슬·낚시는 후속 구현 범위입니다.

## 검증

자동 검사 **111개**와 웹·오프라인 빌드가 통과했습니다. 검사에는 입구 기준 경사면 평탄화·이전 지형 복원·2D 얼굴 깜빡임과 입 모양·위험 시간 경계와5% 확률, 점프로 장애물/실제 강 건너기·발판 착지/낙하·천장·부력/잠수/얕은 물가 탈출, 등산길 폭 전체의 완만한 경사와 물리 이동, 네 바퀴 방향별 접지·서스펜션·중력 낙하·길 높이 일치, 동물5종 선택·관절 모션·하늘을 향한 눕기 시점, 집 장비와 현관까지의 실제 이동 경로, 여섯 교통편의 안전한 도착, 차량 가속·후진·제동·고속 충돌·안전 하차, 전체 지도 경계 투영, 무작위 비행 간격·방향·꼬리구름·밤하늘 일정과 날씨별 가시성, 정상까지 실제 이동 계산으로 통과하는 산길, 급경사 통과 방지, 2배 높은 평탄한 정상, 경계·물 이동·캠핑 충돌, 가시 천장과 실내등, 모든 텐트 형태의 실제 천창 광선 통과, 앉기→눕기→일어나기 관절 모션, 점프 제한, 제한된 풀 타일 재사용이 포함됩니다.
