# Free Camper

동물 친구와 함께 섬에서 캠핑하는 3D 브라우저 게임입니다. 별도 서버나 외부 에셋 없이 Three.js로 실행합니다. 게임 웹 호스팅은 활성화하지 않습니다.

## 다운로드와 실행

[최신 테스트 ZIP](https://github.com/NEO-82/Free-Cmaper/raw/main/downloads/Free-Camper-Test.zip)을 압축 해제하고 `Free-Camper.html`을 Chrome 또는 Edge로 여세요. 설치나 인터넷 연결이 필요하지 않습니다. 소프트웨어 WebGL 검사와 실제 GPU의 성능은 다를 수 있습니다.

개발 환경은 Node.js24 권장, 최소22.12입니다.

```sh
npm ci
npm start
```

- 클라우드 개발 서버: `npm run dev` (기본5173포트).
- 자동 검사: `npm test`.
- 정적 웹 빌드: `npm run build`.
- 독립 HTML 생성: `npm run build:offline` → `dist-offline/Free-Camper.html`.

브라우저의 WebGL2와 그래픽 가속이 필요합니다. 초기화에 실패하면 오류 내용과 재시도 안내를 표시합니다.

## 주차장에서 섬으로

집 안에서 장비를 모으는 단계와 버스·기차·정류장·역을 제거했습니다. 동물·계절·탈것을 고른 뒤 기본 장비6종을 챙긴 상태로 **내륙 주차장**에서 시작합니다. 가까이 있는 탈것에 F로 타고 **500m 다리**를 직접 건너 섬으로 들어갑니다.

전체 이동 영역은 약 **4,262×3,380m, 14.4072㎢**입니다. 이전7.2036㎢의 **면적2배**이며, 구석에 있는 내륙 영역은 전체 월드 면적의 약5%입니다. 기존 먼 산 파노라마의 모양·색과 배경 범위(5,220×4,140m)는 유지합니다. 플레이어와 차량은 월드 경계를 넘을 수 없습니다.

섬 중앙에는 크기가 다른 산5개(205·245·310·350·410m)가 있습니다. 이 중 **310m와245m 산**에는 폭6m의 좁은 도로가 정상까지 이어집니다. 길이는 각각 약2.88km와2.60km이며, 정상에는 지름64m/60m의 평평한 캠핑 공간과 안내판이 있습니다. 길·땅·보행·바퀴의 접지 높이를 함께 계산합니다. 산길 밖의 급경사와 암벽을 차량으로 통과할 수는 없습니다.

상점은 **4곳만** 있습니다.

1. 내륙 주차장.
2. 섬 쪽 다리 끝에서100m 지점.
3. 310m 산 정상 도로 입구.
4. 245m 산 정상 도로 입구.

각 상점의 문을 F로 열고 안의 주인에게 F로 말을 걸어 거래합니다. 다른 장소에는 상점을 추가하지 않았습니다. M 지도와 작은 지도에 섬·다리·산·도로·상점·차량·캠프·현재 위치가 표시됩니다. 지도에서 클릭 이동은 하지 않습니다.

## 차량과 캠핑카

탈것은 **스쿠터·승용차·SUV·캠핑카**입니다. 최고속도는 직전 버전과 같은 승용차42.67m/s, SUV37.33m/s, 스쿠터26.67m/s, 캠핑카32m/s입니다. 고속에서 지나치게 약해지던 조향을 강화하고 타이어의 횡방향 한계와 조향 복귀를 적용해 반응을 높였습니다. 바퀴별 접지, 지형 피치·롤, 서스펜션, 가감속 하중 이동과 언덕에서의 중력 낙하는 유지합니다.

캠핑카는 기존 형태를 유지하면서 가로·세로·높이를 각각 **10% 확대**했습니다(4.18×8.8×4.51m). 외형뿐 아니라 바퀴 위치·접지·충돌 범위·운전 시점·실내 장착 크기도 함께 조정합니다.

- 앞쪽에서 F: 운전석. 뒤쪽에서 F: 생활공간.
- 출입문 앞을 가로막던 침대를 뒤로 옮기고 조리대를 앞쪽에 배치해 통로를 비웠습니다. 좌우 배치 모두 충돌 없는 위치에 들어가며, 처음 보는 방향도 통로를 향합니다.
- 실내의 침대·조리대·화장실·출입구·운전석을 F로 사용합니다. WASD로 걸어 다닙니다.
- ESC에서 목재3종·침구3종·좌우 가구 배치를 고르고 브라우저에 저장합니다.
- 실내는 실제 주차 장소에 장착됩니다. 벽 구멍과 투명 유리를 통해 바다·나무·하늘을 볼 수 있습니다.

## 캐릭터와 캠핑

기본 캐릭터는 골든리트리버 강아지이며 고양이·양·너구리·사슴을 선택할 수 있습니다. 둥근3D 머리 하나에 **2D 눈·코·입·볼·얼굴 무늬**를 그립니다. 눈 깜빡임과 입 모양은 2D로 움직이며, 귀·양털·뿔·꼬리·작은 배낭은 입체 형태입니다. 모델·텍스처·음악은 자체 생성하며 참고 작품의 상용 에셋을 사용하지 않습니다.

텐트는 기본9×8×5m이며 크기·형태·색·원단을 선택합니다. 장애물이 없는 육지에 설치하면 **입구 높이를 기준으로 텐트 면적만 평평하게** 깎거나 메웁니다. 밖의 땅을 유지하며, 재설치하면 이전 장소의 지형을 복원합니다. 텐트 안에서 문·침대·가방·랜턴을 사용할 수 있습니다. 모닥불은 자동으로 생성하지 않습니다.

기본 점프는 초기 구현보다2배 높습니다(약4.3m). Shift로 이동하다 점프하면 일반 점프보다 높이·거리 약1.2배입니다. 나무 가지·수관과 바위의 실제 표면 위에 올라갈 수 있습니다. 지지면을 벗어나거나 벌목·채광으로 사라지면 떨어집니다.

## 바다·야생동물·하늘

해변은 기존 모래색과 완만한 해안의 형태를 섬 둘레로 이어갑니다. 잔잔한 파도는 최대약16cm이며 옅은 물거품이 오갑니다. 바다·강·호수에서 수영하고 Q로 잠수, Space로 상승합니다. 꽃게14마리·소라20개·바닷가제16마리는 F로 채집해 식재료로 보관합니다. 물고기·거북·산호·해초도 관찰할 수 있습니다.

일반 사슴·토끼·여우·올빼미는 여행마다 무작위 위치에 배치합니다. 위험 동물은 곰·뱀·늑대이며 **23:00 이상~다음 날06:00 미만**에 게임 한 시간마다 기본5% 확률로 등장합니다. 청소와 퇴치 장비를 모두 갖추면 기존0.5% 보호 효과가 적용됩니다. 동시에 한 마리만 나타나며, 오전6시·실내 대피·물 진입·퇴치에서 사라집니다.

현실120초가 게임 한 시간입니다. 날씨는 게임 한 시간마다 맑음70%, 비/눈10%, 흐림10%, 안개10%로 추첨합니다. 겨울의 강수는 눈입니다. 먼 비행기는 평균 게임 한 시간마다, 은하수는2~3일 간격의 밤에 나타납니다. 겨울의 맑은 밤에는 오로라가 보입니다. ESC·가방·지도에서는 시간·움직임·파도·하늘 연출이 정지합니다.

## 조작

| 조작 | 동작 |
|---|---|
| WASD / 방향키 | 도보·실내 이동, 운전 시 전진·후진·조향 |
| 마우스 / 휠 | 시점 회전 / 확대·축소. 도보·차량 모두 최대 확대 시1인칭 |
| F | 승하차·문·상점·채집·실내 시설 |
| Space | 점프, 물에서 상승, 운전 시 제동 |
| Q | 잠수 |
| 왼쪽 Shift / Ctrl | 달리기 / 천천히 걷기 |
| C / V | 앉기 / 엎드리기 |
| B / M / ESC | 가방 / 전체 지도 / 정지 메뉴 |

정차한 뒤 F로 내립니다. 나무·바위·건물·급경사·물·경계와 충돌하며, 다리에는 가드레일이 있습니다. 야외 기본 걷기8m/s, 달리기24m/s이며 차량 최고속도와는 별도입니다.

## 검증과 남은 범위

**자동 검사113개**, 웹·오프라인 빌드가 통과했습니다. 자동 검사는 섬 면적·해안·내륙 비율·500m 다리의 네 차량/보행 통과, 산과 캠핑장·도로·지도, 캠핑카 두 배치의 실제 출입 위치에서 시설까지 이동, 바퀴 접지·충돌·핸들링, 텐트 지형·2D 표정·점프·수영·야생동물·날씨를 확인합니다. 브라우저에서는 실제 월드의 도로 표면 광선, 실내 진입·이동·꾸미기·하차, 상점별 거래와 정상 캠핑을 확인합니다. 독립 HTML은 네트워크를 끈 상태에서 실행을 검사합니다.

게임 진행 저장/불러오기, 해산물 요리·섭취, 정교한 야생동물 추격·공격, 차량 연료·파손·구매는 아직 없습니다. 옵션과 캠핑카 꾸미기는 브라우저에 저장됩니다.
